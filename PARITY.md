# List parity: React vs Vue

| Priority | Difference                                  | React                                                                                                                         | Vue                                                                                                                                                                                                                                                                                                    |
| -------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| High     | Filters shape                               | Does not compile: still uses the old `Filters` record, `DEFAULT_FILTERS` as an object and a `filters` prop that is controlled | `State.filters` is `FilterState[]` (`{ column, value, isDirty }`), `setFilter(column, value)` and `setFilters({ column: value })` (they merge into the list), `onFiltersChange(FilterState[])`; `filters` prop is the initial `Filter[]`, read once into `localFilters`. There is no `v-model:filters` |
| High     | Columns shape                               | Does not compile: still uses `columnSettings` and `updateColumn`, and column objects with free-form keys                      | `State.columns` is `Columns` (`{ name, label, visibility, ...your keys }`, `visibility` defaults to `true`), `columnSettings` and `updateColumn` are gone; `setColumn(column, key, value)` sets one key of one column; `columns` is a required prop and the list never derives columns from the rows   |
| Medium   | `ListColumns` slots                         | `children` render function and a `column` render prop                                                                         | `columns` slot `{ context, setColumn }` and one slot per column `{ context, name, label, visibility, ...your keys, setValue(key, value) }`                                                                                                                                                             |
| Medium   | `requestTrigger` in `State`                 | Missing                                                                                                                       | Set by every action before the request (`RequestTrigger`); it replaces `isRefresh`, which Vue no longer has (a refresh is `isLoading` with `requestTrigger === 'refresh'`)                                                                                                                                                                                                                                              |
| Medium   | `ListFilters` component                     | Missing                                                                                                                       | `filters` slot `{ context, setFilter, setFilters }` and one slot per column `{ context, column, value, isDirty, setValue }`                                                                                                                                                                            |
| Low      | `setPage(page)` with the page already shown | Refetches that page                                                                                                           | Does nothing: Vue starts requests from a watcher on the local page, search, sort and per-page values, so an unchanged value does not fire it. Use `refresh` to refetch                                                                                                                                 |

Remove a row once it is fixed, and add one when a new difference shows up.
